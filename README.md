# 💰 Python Expense Tracker

A lightweight, command-line Expense Tracker built in Python to log, categorize, and analyze personal spending. Built as part of my core Python engineering journey to practice structured data handling, modular architecture, and persistent storage.

---

## ✨ Key Features

- **Log Expenses:** Record daily transactions with amount, category, date, and description.
- **View & Filter History:** Display all recorded expenses or filter transactions by specific categories.
- **Spending Summary:** Automatically calculate total expenditure and category-wise breakdowns.
- **Persistent Storage:** Saves transaction records locally so data remains intact after closing the terminal.
- **Input Validation:** Handles invalid numeric inputs and missing file states cleanly without crashing.

---

## 🛠️ Tech Stack & Concepts Used

- **Language:** Python 3.x
- **Core Concepts:** Object-Oriented Programming (OOP), File I/O & Context Managers (`with`), Exception Handling (`try/except`), Modular Functions, and CLI Menu Loops (`while True`).
- **Storage:** Local Database / File Persistence (`SQLite3` / `JSON` / `CSV`)
